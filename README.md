# my-first-site

黃大象 — Doula・身心靈健康分享 個人自我介紹網頁。

## 內容

單頁式靜態網站，莫蘭迪奶茶杏色系設計，包含：

- 首頁形象照與自我介紹
- 關於我
- Doula 服務介紹
- 身心靈健康分享
- 聯絡方式

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 完整網頁，CSS 與形象照（base64）皆已內嵌，單一檔案即可運作 |
| `photo.jpg` | 形象照的網頁優化版備份（533×800） |

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## 部署

靜態網站，將 repo 連接至任何靜態主機（Zeabur / Netlify / Vercel / GitHub Pages）即可，無需建置步驟。
